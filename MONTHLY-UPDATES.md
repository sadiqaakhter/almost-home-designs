# Monthly homepage updates

Edit `content/monthly.json` in GitHub and commit to main. GitHub Pages publishes the update. Keep the quotes and commas intact.

- `featured`: the six quick links at the top. Change title, eyebrow, image path, alt text and destination.
- `project`: project-page title, description, details and images. Add images to the images array to expand the gallery.
- `events`: replace dates, names and addresses when the market schedule changes. The supplied flyer does not specify a year; confirm the schedule with the client before reusing it.
- `newsletter`: leave signupUrl empty until Wix provides the real signup page. Then add its https URL and update the coming-soon text.

Upload new photos into assets/editorial first. Use lowercase filenames without spaces and descriptive alt text. Keep photos below about 500 KB where practical. The page has static fallback content; update the corresponding HTML when making a permanent change for search engines and visitors without JavaScript.

Product prices: fruit mug strainer US$65, shell trinket dish US$12 (client supplied); small trinket dish US$18 (client selected Etsy price). Mugs and mug candles are enquiry-only. No live payment processing is connected. Generated cutouts are labeled AI-enhanced; real project, team, candle, event and article photographs remain original.
